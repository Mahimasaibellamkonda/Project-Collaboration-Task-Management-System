# ProjectFlow

## Project Collaboration & Task Management System

ProjectFlow is a professional web-based project collaboration and task management application designed to help teams organize projects, assign tasks, track progress and manage team members from a centralized dashboard.

---

## Features

### Dashboard
- Overview of active projects
- Total task count
- Completed tasks
- Tasks due soon
- Project progress
- Recent tasks

### Project Management
- Create new projects
- View all projects
- Filter projects
- Track project progress
- Set project deadlines
- Delete projects

### Task Management
- Create tasks
- Assign tasks to team members
- Set task priority
- Set deadlines
- Track task status
- Search tasks
- Filter by status
- Filter by priority
- Mark tasks as completed
- Delete tasks

### Team Management
- Add team members
- Store member details
- Display team roles
- Display email information

### Data Persistence
The application uses browser LocalStorage to preserve project, task and team data even after refreshing the page.
